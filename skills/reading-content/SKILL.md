---
name: reading-content
description: >-
  Writes and reviews learner-facing text anywhere in a course: reading
  sections, exercise instructions, hints, and test or check prompts. Keeps
  text in short sections, replaces label/value bullet lists with tables,
  highlights key notes and warnings, adds comprehension checks, and keeps the
  focus on the Cloudflare product's distinguishing features and gotchas. Use
  when drafting, revising or assessing any course text a learner will read,
  including content presented in an agent's terminal.
---

- Break the content into short sections.
- Visually distinguish the reading content; for example; in an agent's terminal, you might want to present the content like a presentation; if key note or warning, highlight in bold.
- Each section should allow include some interaction with the learner to ensure what was presented is clear. You can elicit questions.
- Use a table instead of a bullet point list if the bullet point list is for the form `- <short description/label>: <Content>`
- Focus on the Cloudflare product, the distinguishing features, the gotchas.
- Repeating key points in relevant sections is okay.
